# Celsius AI - Namecheap Deployment (WSGI Version) 
 
1. Upload all files to your Python app directory 
2. In cPanel Python App settings: 
   - Startup File: app.py 
   - Application Entry Point: application 
3. Restart the Python app 
4. Visit your domain to see Celsius AI 
 
This version uses pure Python WSGI - no external dependencies required!
